# 05 — Program Execution Tracker

## Business question
How can a cross-functional initiative keep workstreams, owners, milestones, risks, and decisions visible?

## Templates
- `data/workstream_tracker_template.csv`
- `data/risk_log_template.csv`

Open the CSVs in Excel or Google Sheets. Replace example rows with a real program only when you have permission to share the information.

## Suggested governance
- Weekly workstream review: milestones, dependencies, blockers, and decisions.
- Risk review: probability, impact, mitigation, owner, due date.
- Executive update: objective, KPI baseline, target, current status, key risks, decisions needed.
- Closeout: outcome versus target, lessons learned, and next actions.
